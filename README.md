# Syberchess Support

Static support, privacy, and license information for Syberchess.
Published from `main` with GitHub Pages at `https://leonardobohac.github.io/syberchess-support/`.
The old `saberchess-support` site forwards existing links to this site. Keep those
redirects while App Store Connect still references the old URLs.

The app continues to use Apple's Standard EULA. `terms.html` provides product
information and third-party notices; it is not a replacement custom EULA.
No scripts, analytics, remote fonts, or forms are included.

The privacy policy distinguishes local app settings, voluntary support email,
GitHub Pages logs, and Apple platform services. Support retention is based on
need, not an automated timer. The operator must apply the stated retention and
privacy-request practices to actual correspondence; publishing a policy does not
automate mailbox deletion or change providers' logs and backups.

Use a GitHub noreply address for commit authorship.
